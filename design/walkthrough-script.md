# 60-second walkthrough script

Record the web demo (screen capture plus mic), with **Voice** on. Keep it under 60 seconds.

| Time | Show | Say |
|---|---|---|
| 0-8s | Demo page, idle | "New users abandon screen-driven setup on voice devices. First Words gets them to a first task by voice alone." |
| 8-25s | Click **Start**, say "Sam", tap **Music** on the screen | "One question per turn. The name is used once, the choices are spoken, and the screen mirrors the voice. It ends with exactly what to say next." |
| 25-38s | Play **Misrecognition** | "When it hears something close, like 'neus,' it confirms before acting." |
| 38-48s | Play **Recovery**, point at the design notes | "Recovery rephrases and adds an example instead of repeating. Every turn is tagged with the principle behind it." |
| 48-60s | README "How it's built" diagram | "The demo and the Alexa skill share one dialog engine, and the tests check the design principles. The skill isn't deployed yet; next step is user testing." |
