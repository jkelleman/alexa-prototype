# 60-second walkthrough script

Record in the Alexa Developer Console Test tab (screen capture plus mic). Keep it under 60 seconds.

| Time | Show | Say |
|---|---|---|
| 0-8s | `README.md` problem and principles | "New users abandon screen-driven setup on voice devices. This prototype gets them to a first task by voice alone." |
| 8-30s | Simulator: "open onboarding demo", answer name, then "music" | "One question per turn, the name is used once, and the choices are spoken so the user knows what to say." |
| 30-42s | Simulator: stay silent or say nonsense | "Recovery rephrases with an example instead of repeating or blaming." |
| 42-52s | `design/dialogs.md` before/after on the ungrounded answer | "I scored dialogs against a rubric. This one invented a capability, and the fix claims only what's built." |
| 52-60s | `README.md` status section | "Scores are self-scored and the APL is untested on device. Next step is user testing." |

Record only after the skill runs in the simulator, and keep the honest-status close.
