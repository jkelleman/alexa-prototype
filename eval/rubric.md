# Rubric

Score each dialog 0-2 per criterion (max 10).

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Brevity | Over 2 sentences per turn | 2 sentences | 1 short sentence |
| Single question | Multiple questions | Implied second | Exactly one |
| Grounding | Invents facts | Vague | Only user or known data |
| Recovery | Dead end | Repeats verbatim | Rephrases, offers choices |
| Next step clarity | Unclear | Implied | Explicit what to say |
